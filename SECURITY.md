# Security Policy

## Supported Versions

Fence is pre-1.0. Security fixes target the latest released version.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Email the maintainer listed on the GitHub profile, or open a private security advisory on GitHub if available. Include:

- Affected version or commit.
- Reproduction steps.
- Expected and actual impact.
- Any suggested fix or mitigation.

We aim to acknowledge reports within 7 days.
